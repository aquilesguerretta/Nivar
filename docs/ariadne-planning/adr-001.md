# ADR 001 — planning branches from a retained reviewed Core state

Register `demand_contract_screening` / `0.1.0` / `ariadne.plan.demand_contract_screening.v0_1_0` as a separate exact deterministic executor. Do not extend the financial semantics of Close v0.1/v0.2 or the scalar demo model.

The observed state is the exact existing Core version bound to a saved reviewed result. Add only a narrowly reviewed demand-fact intake record shape; Close may preserve these as unsupported component observations. Planning derives supported facts and contextual reference bindings from those frozen records. Originals, source confirmations and evidence remain in existing storage/Core chains. No schema or second source of truth is required.

Saved assumptions and scenarios use existing Core primitives. Scenario metadata records its baseline result and optional parent result for branching. Existing workspace transaction receipts provide retry safety. Private planning paths reuse normal operator/workspace checks and development preflight before request body consumption. Replay uses exact registered metadata and frozen source/rule inputs.

Authority and tariff applicability are separate from software execution. The implementation is a bounded historical normal-regime screening model; explicit assumptions and partial coverage remain part of every result. No recommendation, tax reconstruction or commercial activation follows.
