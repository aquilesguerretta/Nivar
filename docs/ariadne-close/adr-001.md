# ADR 001 — additive exact model dispatch for assisted close

Reuse Core PrivateObject, immutable StateVersion/EvidenceRef, AssumptionVersion, Scenario, ModelVersion, ModelRun and Result. Add one exact metadata dispatch for `assisted_close` 0.1.0 with decimal string inputs and a separate result key. Scalar identity, integer behavior, default configuration and replay remain unchanged.

Close-specific tables hold bounded intake originals/previews, workspace review identity, idempotency receipts and append-only operator treatments/packages. Confirmed inputs and authoritative computations live in Core state/run/result only. One batch confirmation state aggregates rows; no operator creates row-level Core primitives. Calculation assembles exact confirmation versions into one immutable review state with source references. A small additive migration links these private records; no edits to migrations 0012–0015 or destructive Core schema change.

Keep executor v0.1.0 available for historical replay when future versions are added. Corrections append confirmations/source revisions and new runs. Export packages snapshot treatments as well as the exact calculation. Transactional workspace locking and request hashes serialize consequential writes and recover a committed response after transport loss.
