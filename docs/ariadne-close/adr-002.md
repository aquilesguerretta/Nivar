# ADR 002 — inspected sources and exact observation executor

v0.1 parser/executor is retained. Opt-in inspection v2 shares the existing private upload route's preflight/isolation boundaries, inventories passive layout complexity, and records selected regions/default origins. It does not execute formulas or promote caches/hidden content. Metadata URLs are attributed strings, never fetched.

The authentic invoice has unknown tax basis. It is inappropriate to invent inclusive/exclusive values to satisfy the old normalized financial contract. v0.2 adds a separate confirmed-observation record kind for supported native invoice arithmetic. Those observations never enter independent verification. Canonical mapped records continue through the unchanged v0.1 executor. Exact v0.2 metadata/policy/assumption dispatch is added alongside v0.1; scalar dispatch is unchanged. New review creation explicitly chooses v0.2, while existing reviews retain their fixed version-1 assumption and exact historical executor. No migration or shadow result storage.

Context acknowledgement freezes raw contextual source rows without manufacturing financial inputs. Source preview, attributed derivative/filter provenance, confirmation choices and exclusion inventory flow through the existing Core state/run/result and immutable export package. History remains reconstructible. A lost write response uses existing same-transaction receipts; inspection itself is read-only. No lifecycle/delete feature is added.

The in-app browser cannot render an embedded PDF blob reliably. A route-scoped private page PNG replaces the blank iframe. It renders retained originals, not corpus-specific images, through pypdfium2/Pillow in a deadline-bounded disposable process. PDFium is [not thread-safe](https://pypdfium2.readthedocs.io/en/stable/python_api.html); process isolation also permits termination. A raster-specific guard rejects Form XObjects, bounds declared/native image dimensions and decoded image allocation, and supports only bounded passive image filters. No form environment or annotation rendering is enabled. Page preview is optional and cannot confer calculation eligibility. Auth, original downloads and static/public storage remain unchanged. This is a small dependency/route extension, with no new persistent truth or migration.

A review's version1 assumption fixes its rule policy. Inspection imports into retained v0.1 reviews fail before parsing; exact v0.1 historical runs still replay. Confirmation evidence uses the same frozen normalization identity as its payload. Result identity participates in UI stale-write guards; excluded confirmation rows survive refresh. Saved package links resolve an immutable package for the selected result after reload, never a newer result.
